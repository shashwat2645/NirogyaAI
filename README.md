# NirogyaAI - AI-Based Disease Prediction System

NirogyaAI is a healthcare web application that leverages Machine Learning to predict potential diseases based on user-entered symptoms. The application provides an intuitive interface for users to input symptoms and receive a predicted disease along with basic health precautions and recommendations.

## Features

* User Registration & Login
* Disease Prediction using Machine Learning
* Symptom-Based Health Assessment
* Health Precautions & Recommendations
* Responsive and User-Friendly Interface
* Secure Data Storage using MySQL
* Backend developed using Django

## How It Works

1. Users register and log in to the application.
2. The user selects or enters symptoms through the web interface.
3. The symptom data is processed by the Django backend.
4. The trained Machine Learning model predicts the most probable disease.
5. The application displays the predicted disease along with health precautions and recommendations.
6. User data is securely managed using MySQL.
